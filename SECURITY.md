# Security Policy

## Status

Trestly App connects users to a **testnet-only** Soroban contract. It is a
demonstration and integration reference, not a mainnet custody product.

## Reporting a vulnerability

Report frontend vulnerabilities privately through GitHub's repository
security-advisory flow when available. Do not publish private keys, seed
phrases, wallet session data, or signed transaction XDR in an issue.

For contract-level concerns, also report to
[trestly-contract](https://github.com/Trestly-team/trestly-contract/security).

## User safety

- Trestly never needs your Freighter recovery phrase or private key.
- Only approve transactions after reviewing their network and contract details.
- The current deployment is on Stellar Testnet; testnet assets have no value.
- A named arbiter has final authority over any dispute they are assigned.
